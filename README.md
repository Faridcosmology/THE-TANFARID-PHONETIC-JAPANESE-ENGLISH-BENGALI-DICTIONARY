بِسْمِ اللهِ الرَّحْمٰنِ الرَّحِيْمِ
সমস্ত প্রশংসা মহান আল্লাহর, যিনি ভাষার বৈচিত্র্য সৃষ্টি করেছেন এবং মানুষের মধ্যে ভাবের আদান-প্রদানের পথ খুলে দিয়েছেন। দরুদ ও সালাম বর্ষিত হোক সেই মহামানবের প্রতি, যাঁর বাণী আজও সমগ্র মানবতার পথপ্রদর্শক।
ভাষার দেয়াল, আর লিপির দরজা
জাপানি ভাষা শেখার পথে বাংলাভাষী শিক্ষার্থীর প্রথম ও সবচেয়ে বড় বাধা হলো লিপি। জাপানিতে তিনটি লিপি একসঙ্গে চলে—হিরাগানা, কাতাকানা আর কাঞ্জি। হিরাগানা ও কাতাকানা শেখা যায়; কিন্তু কাঞ্জি—হাজার হাজার চীনা অক্ষর—শিখতে বছরের পর বছর লেগে যায়। ফলে অনেক আগ্রহী শিক্ষার্থী শুরু করেই থেমে যান। ভাষার দেয়াল তৈরি হয় না—দেয়াল তৈরি হয় লিপির।
এই অভিধান সেই দেয়াল ভাঙার একটি ছোট্ট প্রয়াস। এর মূল ভাবনা সহজ: যদি জাপানি শব্দ বাংলা অক্ষরে পড়া যায়, তবে বাংলাভাষী শিক্ষার্থী জাপানি লিপি না জানলেও শব্দটি পড়তে, বলতে ও মনে রাখতে পারবেন। এই ভাবনা থেকেই জন্ম নিয়েছে "TANFARID Phonetic System"—জাপানি কানা থেকে বাংলা বর্ণমালায় ধ্বনিভিত্তিক রূপান্তরের একটি নিয়মবদ্ধ পদ্ধতি।
এই বই কী, আর কী নয়
এটি কোনো পূর্ণাঙ্গ অভিধান নয়। এটি একটি মিনি-অভিধান—দৈনন্দিন জীবনের প্রয়োজনীয় এক হাজার শব্দ ও বাক্যাংশের সংকলন। প্রতিটি এন্ট্রিতে রয়েছে:
•	বাংলা লিপ্যে উচ্চারণ (যেমন: わたし → ওয়াতাশি)
•	মূল জাপানি রূপ (কানা ও কাঞ্জি)
•	ইংরেজি অর্থ
•	মৌলিক বাংলা সংজ্ঞা ও উদাহরণ
শব্দগুলো অভিধান-ক্রমে (あ→わ) সাজানো, তবে ব্যবহারিক প্রয়োজনে বিভাগভিত্তিক সূচিও দেওয়া হয়েছে—যেমন অভিবাদন, সংখ্যা, খাদ্য, পরিবহন, সংকট-শব্দভাণ্ডার, জরুরি বাক্যাংশ।
এটি প্রমিত জাপানি উচ্চারণের বিকল্প নয়। বাংলা লিপ্যন্তর উচ্চারণের একটি আনুমানিক রূপ দেয়; সূক্ষ্ম ধ্বনিগত পার্থক্য (যেমন পিচ-অ্যাকসেন্ট) বাংলা অক্ষরে ধরা যায় না। তাই এই বইকে শেখার সিঁড়ি হিসেবে দেখুন—গন্তব্য হিসেবে নয়।
কেন এই উদ্যোগ
জাপান ও বাংলাদেশের মধ্যে মানুষের বন্ধন দিনে দিনে বাড়ছে—শিক্ষা, কাজ, ব্যবসা, সংস্কৃতি। জাপানে বসবাসরত বাংলাভাষী মানুষের সংখ্যাও কম নয়। অথচ বাংলাভাষী শিক্ষার্থীর জন্য জাপানি শেখার সহজ, নিজস্ব কোনো অভিধান নেই। এই অভিধান সেই শূন্যতা পূরণের একটি ক্ষুদ্র প্রচেষ্টা—যাতে ভাষা শেখার প্রথম ধাপটুকু সহজ হয়।
আমার বিশ্বাস, প্রত্যেক জাতির নিজের লিপিতে জ্ঞান আহরণের অধিকার রয়েছে। এই বই সেই বিশ্বাসেরই একটি প্রকাশ—"Orthographic Liberation Series"-এর প্রথম খণ্ড।

১. অ-মহাপ্রাণ নীতি (No Aspiration): জাপানি ভাষায় বাংলার মতো মহাপ্রাণ বর্ণ (খ, ঘ, ছ, ঝ, ঠ, ঢ, থ, ধ, ফ, ভ) আলাদা করে নেই। তাদের সমস্ত ধ্বনি অ-মহাপ্রাণ (ক, গ, চ, জ, ত, দ, প, ব)। তাই বাংলা ব্যঞ্জনবর্ণগুলোর নিখুঁত জাপানি রূপান্তর করতে গিয়ে আমরা এই বৈজ্ঞানিক সরলতা বজায় রেখেছি। ২. 'ল' ও 'র' ধ্বনি: জাপানিতে ইংরেজি বা বাংলার মতো স্বতন্ত্র 'L' ধ্বনি নেই; তাদের ら行 (Ra-Ri-Ru-Re-Ro) ধ্বনিটিই 'র' এবং 'ল' উভয়ের কাজ চালিয়ে নেয়।
জাপানি হরফ দিয়ে বাংলা কার-চিহ্ন ও মাত্রারূপ বিন্যাস
১. আ-কার ( া )
জাপানি মৌলিক ধ্বনির সাথে আ-কার যুক্ত করতে হলে ধ্বনির শেষে あ (আ) অথবা দীর্ঘ স্বর চিহ্ন ー ব্যবহার করা হয়।
•	ক + া = কা: か (Ka)
•	স + া = সা: さ (Sa)
•	ত + া = তা: た (Ta)
•	উদাহরণ:
o	カレー (Kare- / কারেএ → কারি)
o	おかあさん (Okaasan / ওকাআসান → মা)
২. ই-কার ( ি ) ও ঈ-কার ( ী )
জাপানি ভাষার い (ই) ধ্বনি দিয়ে হ্রস্ব ও দীর্ঘ ই-কার দুটোই নিখুঁতভাবে প্রকাশ করা হয়।
•	ক + ি = কি: き (Ki)
•	স + ি = শি: し (Shi)
•	ন + ি = নি: に (Ni)
•	উদাহরণ:
o	にほん (Nihon / নিহোন → জাপান)
o	みず (Mizu / মিজু → পানি)
৩. উ-কার ( ু ) ও ঊ-কার ( ূ )
জাপানি ভাষার う (উ) ধ্বনি ব্যবহার করে উ-কার ও ঊ-কার লেখা হয়।
•	ক + ু = কু: く (Ku)
•	স + ু = সু: す (Su)
•	হ + ু = ফু: ふ (Fu)
•	উদাহরণ:
o	すし (Sushi / সুশি)
o	くるま (Kuruma / কুরুমা → গাড়ি)
৪. ঋ-কার ( ৃ )
জাপানিতে সরাসরি ঋ-কার নেই, তাই ধ্বনিগতভাবে এটি り (রি) দিয়ে প্রকাশ করা হয়।
•	ত + ৃ = ত্রি/তরি: とり (Tori / তোরি → পাখি)
৫. এ-কার ( ে )
জাপানি ভাষার え (এ) বা এ-বর্গীয় কানা দিয়ে এ-কার প্রকাশ করা হয়।
•	ক + ে = কে: け (Ke)
•	ত + ে = তে: て (Te)
•	ন + ে = নে: ね (Ne)
•	উদাহরণ:
o	せんせい (Sensei / সেন্সেই → শিক্ষক)
৬. ঐ-কার ( ৈ )
জাপানি ভাষায় えい (ei) বা あい (ai) মিলে ঐ-কারের ধ্বনি তৈরি করে।
•	ক + ৈ = কেই/কাই: かい (Kai) বা けい (Kei)
•	উদাহরণ:
o	けいかん (Keikan / কেইকান → পুলিশ)
৭. ও-কার ( ো )
জাপানি ভাষার お (ও) অথবা おう / おお (ওও) ধ্বনি দিয়ে ও-কার নিখুঁতভাবে ফুটিয়ে তোলা হয়।
•	ক + ো = কো: こ (Ko)
•	স + ো = সো: そ (So)
•	ত + ো = তো: と (To)
•	উদাহরণ:
o	こども (Kodomo / কোদোমো → শিশু)
o	とうきょう (Toukyou / তোওকিওও → টোকিও)
৮. ঔ-কার ( ৌ )
জাপানি ভাষার おう (ou) বা おおい ধ্বনি দিয়ে ঔ-কার বা ওউ ধ্বনি তৈরি হয়।
•	ক + ৌ = কোউ: こう (Kou)
•	ত + ৌ = তোউ: とう (Tou)
•	উদাহরণ:
o	こうこう (Koukou / কোউকৌ → হাই স্কুল)
৯. হসন্ত ( ্ ) ও সোকুওন ( っ )
জাপানি ভাষায় শব্দের মাঝে বা শেষে ব্যঞ্জন ধ্বনি থামিয়ে দিতে বা যুক্ত করতে ছোট っ (সোকুওন) ব্যবহার করা হয়, যা বাংলায় হসন্ত বা দ্বিগুণ ব্যঞ্জন হিসেবে প্রকাশ পায়।
•	ক + ্ত = ক্ত/ত্: きって (Kitte / কিত্তে)
•	স + ্স = স্স: いっしょ (Issho / ইশ্শো)
১০. অনুস্বার ( ং ) ও হাৎসুওন ( ん )
জাপানি ভাষার ん (ন/ং/ম) দিয়ে বাংলায় অনুস্বার বা ন-ফলা প্রকাশ করা হয়।
•	ব + ং/ম = িম্বু / ঙ্গ:
o	しんぶん (Shinbun / শিম্বুন্)
o	にほんご (Nihongo / নিহোঙ্গো)
